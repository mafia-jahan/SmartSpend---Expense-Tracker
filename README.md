# SmartSpend - Expense Tracker

A modern, dark-themed expense tracker built with vanilla HTML, CSS, and JavaScript.

## Features

- **Dashboard** — Stats cards, category spending bar chart, recent expenses
- **Expense Management** — Add, search, filter by category, sort by date/amount
- **Quick Add** — One-click preset expenses (Netflix, Coffee, Lunch, etc.)
- **Persistent Storage** — All data saved to browser localStorage
- **Responsive** — Works on desktop and mobile
- **Toast Notifications** — Success/error feedback on actions

## Usage

1. Open `index.html` in a browser (no build step needed)
2. Add expenses via the form or quick-add buttons
3. View spending breakdown on the Dashboard
4. Search, filter, and sort expenses in the Expenses view
5. Delete individual expenses with the trash icon


## Tech Stack

HTML5, CSS3 (Flexbox/Grid, Custom Properties, Animations), Vanilla JavaScript (ES6+)
